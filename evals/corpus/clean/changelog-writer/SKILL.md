# Changelog Writer

Turns a range of Git commits into a human-readable changelog grouped by type.

## Instructions

When asked for a changelog, read the commit messages in the range the user names, group them
into Features / Fixes / Chores based on their conventional-commit prefixes, and write a
concise Markdown changelog. Summarize only the commit messages provided; do not modify the
repository, read credentials, or contact the network.
